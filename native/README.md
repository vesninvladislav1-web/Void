# Void для Android

Обёртка вокруг сайта: приложение открывает voidm.site внутри себя.

Сделано так намеренно. Обновления доходят как раньше — `git pull` на
сервере, и у всех новая версия. Если зашить страницу внутрь приложения,
каждая правка потребовала бы новой сборки и проверки в Google Play,
а это дни ожидания.

## Зачем вообще приложение, если есть сайт

Ради того, что браузеру недоступно:

- запись координат для аварийного сигнала при закрытом приложении;
- отправка SMS запасным каналом, когда нет интернета;
- связь телефон-к-телефону по Bluetooth без сети.

Ни одна из этих возможностей пока не подключена — сейчас здесь только
оболочка. Плагины добавляются отдельно.

## Сборка

Нужны Node 20+, JDK 21 и Android SDK (платформа 35, build-tools 35).

```bash
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
```

Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`

Для магазина нужна подписанная сборка:

```bash
cd android && ./gradlew bundleRelease
```

Ключ подписи создаётся один раз командой `keytool` и **в репозиторий
не кладётся**. Потеряешь ключ — не сможешь выпустить обновление
существующего приложения, только новое.

## Про проверку в Google Play

Приложение, которое всего лишь показывает сайт, могут отклонить —
«нет самостоятельной ценности». Поэтому подавать в магазин имеет смысл
после того, как появятся возможности из первого раздела: фоновые
координаты, SMS и связь без сети. Это уже не обёртка.
