# Живой стенд

Настоящий клиент Void на настоящем сервере, управляемый из командной строки.
Скрипт открывает `index.html` в безголовом Chromium и жмёт те же функции,
что и человек: регистрация, ключи, шифрование — всё делает сам клиент.
Ничего своего он не шифрует и мимо клиента не отправляет.

Зачем: проверять то, что видно только вживую — nginx, сертификаты,
доставку писем через настоящий сервер, — и переписываться с проверяющим
аккаунтом `@claude_code`.

## Установка

```
cd server/stend
npm i playwright ws
npx playwright install chromium     # если Chromium ещё не стоит
```

`package.json` в репозитории не хранится (см. `.gitignore`), поэтому
установка каждый раз руками.

## Запуск

Пароль — только через переменную окружения. В репозитории его нет.

```
VOID_PASS=... node zhivoi.js читать
VOID_PASS=... node zhivoi.js написать "привет"
VOID_PASS=... node zhivoi.js голосовое zapis.webm 2
VOID_PASS=... node zhivoi.js файл foto.jpg
VOID_PASS=... node zhivoi.js снимок
VOID_PASS=... node zhivoi.js завести          # создать аккаунт, один раз
```

Переменные: `VOID_NICK` (по умолчанию `claude_code`), `VOID_TO` (кому
писать, по умолчанию `Void`), `VOID_URL` (по умолчанию `https://voidm.site`),
`CHROME_PATH` (если Chromium лежит не там, где ищет playwright).

## Что надо знать

- **Каждый запуск — чистое устройство.** Сервер отдаёт только то, что
  накопилось, пока нас не было. Своё отправленное после выхода не видно —
  так устроен Void: история живёт на устройстве, не на сервере.
- Голосовое без микрофона: любой `.webm` или `.ogg` с Opus. Собрать можно
  ffmpeg-ом: `ffmpeg -f lavfi -i "sine=frequency=440:duration=2" -c:a libopus golos.webm`.
- Если наружу можно только через HTTPS-прокси (`HTTPS_PROXY` задан),
  браузер не может держать через него WebSocket. Скрипт это обходит сам:
  подменяет странице WebSocket и гоняет кадры через Node. Без прокси
  подмены нет.
- Время в выводе — UTC. Москва — плюс три часа.
