# Свой сервер Войда

Войд можно поднять у себя — на своём VPS или на домашней машине. Тогда
переписка, ключи и аккаунты живут на твоём железе, а общий сервер не
участвует вообще.

Стоит понимать сразу: **сервер и так не читает переписку.** Она шифруется
на устройствах, сервер передаёт шифротекст и не знает, что внутри. Свой
сервер нужен не для этого, а чтобы не зависеть от чужой машины, чужого
домена и чужого кошелька.

## Что нужно

- Linux с Node.js 18 или новее
- Домен и сертификат HTTPS (почему обязательно — ниже)
- Открытый наружу порт

## Установка

```
git clone https://github.com/vesninvladislav1-web/Void.git
cd Void/server
npm install ws better-sqlite3
VOID_ADMIN_PASSWORD='придумай-длинный-пароль' node server.js
```

Всё. База (`void.db`), ключи для уведомлений и аккаунт владельца создаются
сами при первом запуске. Порт по умолчанию 3000, меняется переменной `PORT`.

Чтобы сервер поднимался сам после перезагрузки — в репозитории лежит
`ecosystem.config.js` для pm2:

```
npm install -g pm2
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```

## HTTPS обязателен, и вот почему

Браузер выдаёт доступ к шифрованию (`crypto.subtle`) только на защищённом
соединении. По `http://` его просто нет — а без него Войд не сможет
зашифровать ни одного сообщения и не заработает вообще.

Исключение — `localhost`: на своей машине можно проверять и по http.
Но как только к серверу подключается кто-то ещё, нужен настоящий
сертификат.

Самый простой путь — nginx перед Войдом и бесплатный сертификат:

```
apt install nginx certbot python3-certbot-nginx
certbot --nginx -d твой-домен.ру
```

Конфиг nginx — как в `РАЗВЁРТЫВАНИЕ.md` в корне репозитория: там же описаны
блоки для `/api`, `/signal` (нужен для WebSocket) и `/health`.

## Как подключить к нему приложение

На устройстве: открыть Войд → на стартовом экране внизу **«Свой сервер»** →
ввести адрес → «Проверить и перейти».

Адрес проверяется до сохранения: приложение дёргает `/health` и убеждается,
что там отвечает именно Войд, а не опечатка.

## Что важно знать

**Аккаунты на разных серверах не связаны.** Ник `vlad` на твоём сервере и
`vlad` на общем — разные люди. Переписка с одного не видна на другом, и
написать с одного на другой нельзя: серверы друг о друге не знают. Это как
разные серверы в играх — каждый свой мир.

Переписка со старого сервера при переходе никуда не девается: она лежит на
устройстве и вернётся, если переключиться обратно.

**Резервные копии делай сам.** Скрипт `backup.js` рядом, как им пользоваться
— в `РАЗВЁРТЫВАНИЕ.md`. Копия на той же машине спасает от ошибки, но не от
смерти машины: уноси её куда-то ещё.

**Домашняя машина — не лучший выбор.** Сервер должен быть доступен
круглосуточно: сообщения приходят и ночью, и пока компьютер выключен.
Дешёвый VPS для этого подходит лучше, чем домашний ПК за роутером.
